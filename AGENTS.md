# DevOps Skill Tree

App học DevOps dạng game skill-tree (mô phỏng theo `../solution-architect`).

- **Stack:** Next.js 16 (App Router) + TypeScript + Supabase (Postgres + Auth magic link).
- Chạy được ngay **không cần Supabase** (chế độ local-only, lưu tiến độ trong `localStorage`).
- Nội dung học nằm trong `lib/content.ts` (mảng `NODES`). Muốn thêm/sửa bài học: chỉ sửa file đó.
